Designed as an episodic media streaming service where sections act as episodes, projects are featured as platform **Originals**, and achievements play out like awards season.

## 🛠️ Tech Stack
- **Framework:** React 18, TypeScript
- **Build Tool:** Vite 6
- **Styling:** Tailwind CSS 4
- **Animation & Motion:** Framer Motion 11
- **Smooth Scrolling:** Lenis 1.1

## 🚀 Running Locally

```bash
# 1. Navigate to the project directory
cd "C:\Users\GOKUL\.gemini\antigravity\scratch\gokul-portfolio-series"

# 2. Run the development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```

## 📁 Architecture
- `src/data/portfolio.ts` — The single source of truth for all content, projects, bio, skills, and links.
- `src/components/` — Modular streaming components (Hero billboard, Originals carousel, Top 10 Today, Timeline seasons, Project detail modal, Resume viewer).
- `public/assets/` — Responsive WebP portraits, project screenshots, and PDF resume.
